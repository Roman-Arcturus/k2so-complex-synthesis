`rx-noble-gases` is umbrella name for rare and noble gases like Argon, Helium.

Primary source is condensation from atmosphere. 
The gathered amounts are minimal, so secondary stage of purification/enrichment is needed for industrial production.

recipe_1: [[air_Nauvis]] generates 
```lua
{ type = "fluid", name = "kr-nitrogen", amount = 240 },-- Output 1: Nitrogen 
{ type = "fluid", name = "oxygen", amount = 60 }, -- Output 2: Oxygen 
{ type = "fluid", name = "rx-noble-gases", amount = 3 },-- Output 3: Noble Gases
```
