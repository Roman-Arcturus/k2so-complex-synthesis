# 📦 [[item_rx-wood-chips]]

> **Thematic Description**: Generated by mechanically breaking down bulk forestry lumber into high-surface-area fragments. In industrial processing, wood chipping is the mandatory first step to tear apart heavy cellulose-lignin bonds. This mechanical preparation ensures that fluid wetting agents can evenly saturate the material during chemical washing, refining, and enzymatic fiber separation loops.

## ⚙️ Lua Prototype Manifest

### 1. Item Declaration (`/data.lua`)
```lua
-- 0). test for safety
local k2_assets = "__Krastorio2Assets__" -- K2 graphics, temporary
local crushing_lib = require("__Krastorio2__.prototypes.libraries.crushing")
if not crushing_lib and not crushing_lib.make_recipe then return end

-- 1). define the item
data:extend({
  {
    type = "item",
    name = "rx-wood-chips",
    icon = k2_assets .. "/icons/recipes/wood-with-fertilizer.png", 
    subgroup = "intermediate-product",
    order = "a[biomaterial]-b[wood-chips]",
    stack_size = 200,
    default_request_amount = 50,
    weight = 0.5 * kg, -- Densified for rocket and city-block road transport
  }
})


-- 2). register wood as usable input for kr-crusher
crushing_lib.make_recipe(
  data.raw.item["wood"], {
    subgroup = "intermediate-product",
    order = "a[biomaterial]-b[wood-chips]",
    energy_required = 2,
    results = {
        { type = "item", name = "rx-wood-chips", amount = 2 },
    },
  }
)

```
